# 功能規格：M2 現金庫存與補鈔

對標 DMS「現金模組監看」，升級為**需求預測 + 補鈔排程 + CIT 協作 + 對帳**。

## 功能清單

1. **現金水位**：各機台分鈔匣/面額張數與金額、即時更新。
2. **告警**：空鈔/低水位、滿鈔/拒鈔匣滿、卡鈔；分層門檻。
3. **需求預測檢視**：per 機台未來 N 日提領需求（含面額），含台灣連假/發薪日影響（見 `52`）。
4. **補鈔排程**：依預測 + 水位自動建議裝載量；產生補鈔單；指派 CIT。
5. **CIT 協作**：路線/時窗、到訪 ETA、裝鈔確認、鈔匣交換確認。
6. **清點對帳**：實點 vs 帳上（cash_ledger）差異標記、處理。
7. **閒置現金分析**：在機現金成本、最佳化建議（v2）。

## 主要使用者流程

- **補鈔規劃**：現金組看預測 → 低水位機台清單 → 系統建議裝載量 → 產生補鈔單 → 派 CIT → CIT 確認裝鈔 → 與帳對帳。
- **缺鈔預防**：水位趨勢逼近預測需求 → `CashBelowThreshold` 告警 → 自動建議補鈔單（草稿）。
- **盤點差異**：清點輸入 → 與帳不符 → 開差異 → 查核（可連動對帳/差錯）。

## 畫面

| 畫面 | 重點 |
|---|---|
| 現金總覽 | 區域熱圖、低/缺鈔清單、KPI（閒置現金/缺鈔數）|
| 機台現金詳情 | 鈔匣量表 + 水位趨勢圖 |
| 預測檢視 | per 機台需求曲線 + 信賴區間 + 假日標記 |
| 補鈔排程 | 建議單、批次產單、CIT 指派 |
| CIT 派工板 | 路線、到訪、確認 |
| 清點對帳工作台 | 應有 vs 實點 vs 差異 |

## 補鈔建議邏輯（v1）

1. 取 `cash_forecast`（未來補鈔週期需求）+ 安全庫存緩衝。
2. 目標裝載量 = 預測需求 + 緩衝 − 現有水位，受鈔匣容量限制。
3. 產生 `replenishment_order(Draft)` → 人工確認 `Planned`。
4. v2：以最佳化（最小化造訪次數 + 閒置現金，受缺鈔風險約束）替代單機建議。
