## 做什麼、為什麼

- 蛋小白雞蛋金磚（G02907-01）的分店價 10/5 16:38:51 被請購單 PR2610051056 核准時同步成 64，正確是 42。老闆 11/2 在商品頁改成 42，但商品頁只能「從現在起」，10/19 派出去的貨仍照 64 算。
- 月結／店家每日對帳都在算錢當下回頭查「派車那一刻」的分店價，所以把價目表從 10/5 16:38:51 起改對、重產十月草稿，就能修已派出的帳。
- 修正放在同一個交易裡：
  1. 刪掉 64（26805）與 42（33876）兩個版本，用改價函式 `rpc_upsert_price` 從 10/5 16:38:51 重開「42、沒有結束日」；62（24666）不動。
  2. 重產 2026 年 10 月月結草稿。11 家店合計 −836；4 筆人工調整一筆都不作廢、原樣保留。
- **月結產生器只能整個月、全部店一起重產**（沒有「只算某幾家店」的參數），所以修正檔有兩個方案，由 CEO 裁決後填 `p_mode`：
  - **方案甲**：整月重產後，沒有蛋小白帳的店一律蓋回備份原樣 → 真的只有 11 家店變。
  - **方案乙**：整月採用產生器結果；其他店只要有一分錢、一行不同就整筆停 → 通過的話其他店只有「最後異動時間／明細內部編號」會變。
- 八月以前凍結的月結、九月月結：修正與驗算逐列比對，一個字都不能變。
