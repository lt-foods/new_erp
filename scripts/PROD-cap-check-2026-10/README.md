## 這次改了什麼

- **後台加單**（加單頁送出）：限量團超過整團上限或品項上限 → 整批不送，畫面顯示「已達限量上限：…還剩 N 件，這次要加 M 件」。一次幫多位客人加，用加總算（老闆 10/28 Q1 A、Q3 A）。
- **LINE 記事本留言加單**：要的量超過剩下的 → 只加剩下的量；剩 0 → 整則不加，留言變「錯誤：已達限量上限，未加單（…）」進待處理（Q2 B）。
  - ⚠ 只加到一部分的留言，狀態是「已加單」，說明寫在留言的處理備註（`resolution_note`）裡；**目前不會出現在待處理**。
- 已售的算法跟客人商城下單完全同一套；兩個人同時加同一團會排隊，不會一起超過。
- **不動**：客人商城下單、轉單、互抵銷售、原本的加單函式本身。沒設上限的團行為不變。
