  GRP-20261007-053-0030、GRP-20261007-063-0034、GRP-20261008-018-0038、GRP-20261011-043-0010。

## 貼的時候要注意

- **一次貼一整份**：打開檔案、全選、複製、貼進 SQL Editor、按執行。
- **看到紅字（ERROR）**：截圖給 CEO，⛔ 不要重貼。

## 做了會怎樣／不做會怎樣

- **做了**：
  - 這 4 張單的取貨店變成中和；訂單號、品項、件數、金額、狀態都不變。
  - 總倉派貨工作台的需求是「看取貨店即時算」的，貼完這 4 張的件數就從萬華那一列移到中和那一列，之後照常派到中和。
  - 每張單的備註最後多一行，系統存的是**店的編號**（跟會員頁改取貨店寫的格式一樣），長這樣：
    `[改取貨店] 門市 #萬華店編號 → #中和店編號（2026-10-31 23:30）萬華店停業，2026-10-31 老闆核准改中和取貨`
    （例：萬華店編號是 12、中和店編號是 34，就寫「門市 #12 → #34」。編號是系統裡的數字，01／03 不會列出來，訂單頁備註看得到。）
  - ⚠ 樓下的**派貨草稿**如果已經加過這些商品，草稿上的數字不會自己變（草稿是手改的快照）。
    03 的「派貨草稿_要搬的格子」不是「無」，就照那一欄寫的到草稿頁改：**萬華那格的數字搬到中和那格**（萬華改 0、中和加上同樣件數）。
    只把萬華改 0 不加到中和，中和會少派這幾件。
  - 到貨的 LINE 通知照**中和店**的設定發（看客人有沒有加中和店的 LINE 官方帳號），不是萬華的。
- **不做**：這 4 張一直掛在萬華；萬華停業不派貨，客人等不到貨，到期會變成過期單。
