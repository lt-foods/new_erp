↩ 收貨後怎麼退貨 給分店店員

分店收到貨之後，要把貨退回總倉（瑕疵、客戶取消、客戶拿回來退）就照這張做。
最重要的一步：先看 「客戶取走了沒」，決定要不要勾那個框。

1

找到那張訂單，按退貨

在 訂單列表 / 訂單明細 / 取貨頁，按 ↩ 退貨 或 ↩ 退訂單， 會跳出「退訂單回總倉」視窗。

2

判斷：客戶取走了嗎？（決定要不要勾框）

📦

還沒取走

退瑕疵品 / 客戶取消
👉 不要勾「客戶已取貨後退回」
（一般退貨）
可退 = 已收 − 已取 − 已退
🔄

取走又拿回來

客戶取貨後又退回
👉 勾起「客戶已取貨後退回」
（系統先入庫再退回總倉）
可退 = 已取貨量 − 已退
3

選退貨類型

一般退貨正常退回
破損瑕疵品選這個
過期過期品
4

填數量 → 建立退貨單

在「退多少」填數量（不可超過「可退」），可選填退貨原因， 按 建立退貨單。

✅ 完成！系統會把貨從店端出庫、在途退回總倉，等總倉收貨即結束。 退掉的貨之後會標示「已退貨·不能取貨」，客戶不會再被配到。
⚠️ 注意事項
遇到這些狀況別緊張： • 「可退」是 0？ 先確認畫面有沒有重新整理；確認開的是對的那張單。
• 店長只能退/看自己店的訂單與庫存，別家店的單退不了是正常的。
• 沒有任何「已取貨」的單，「客戶已取貨後退回」會是灰色不能勾 → 請用一般退貨。
• 數量超過「可退」會被擋下；真的庫存不夠系統也會提醒。
