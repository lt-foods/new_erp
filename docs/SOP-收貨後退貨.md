# 店員 SOP：收貨後要退貨怎麼退

> 適用情境：分店已經「收貨」（收進貨／收調撥）後，要把貨退回總倉。
> 例如：收到瑕疵品、客戶取消、客戶取走又拿回來。

---

## 一、先確認：哪種情況？

退貨前先想清楚是下面哪一種，**這會決定一個勾選框要不要勾**：

| 你的情況 | 「客戶已取貨後退回」勾選框 |
|---|---|
| 收了貨，**客戶還沒取**（退瑕疵品 / 客戶取消） | ⬜ **不要勾** |
| 客戶**已經取走、又拿回來**退 | ☑️ **要勾** |

---

## 二、操作步驟

### 步驟 1：找到那張訂單，按退貨

任一個入口都可以：

- **訂單列表**該單那一列 → 按 `↩ 退貨`
- **訂單明細頁**（點進那張單）→ 按 `↩ 退訂單`
- **取貨頁**該單 → 按 `↩ 退貨`

> 📌 退貨按鈕只有在「貨已派到店」之後才會出現（狀態為：派貨中／可取貨／部分取貨／已完成／已過期）。
> 還在「運送中、店裡還沒收到」是不能退的。

### 步驟 2：看懂品項表格

跳出「**退訂單回總倉**」視窗，每個商品一列：

```
SKU │ 品名 │ 訂單量 │ 已取 │ 已退 │ 店端庫存 │ 可退 │ 退多少
```

- **可退** = 系統算好的這次最多能退的數量，不能超過它。

### 步驟 3：決定勾選框（最重要）

- 客戶還沒取 → **不要勾**「客戶已取貨後退回」
  - 可退 = 已收 − 已取 − 已退（＝店裡還在的貨）
- 客戶取走又拿回 → **勾起來**
  - 可退 = 客戶已取走的數量 − 已退

### 步驟 4：選退貨類型

- **一般退貨**：正常退回
- **破損**：瑕疵品選這個（會計會分開記）
- **過期**：過期品

### 步驟 5：填數量、送出

1. 在「**退多少**」填數量（≤ 該列的「可退」）
2. （選填）寫退貨原因，例如「收到瑕疵」「客戶取消」
3. 按 **「建立退貨單（共退 N）」**

完成後系統會開一張退貨單，把貨從店端出庫、在途退回總倉，**等總倉收貨**即完成。

---

## 三、退完之後

- 被退掉的貨，之後在「取貨」視窗會標示 **「已退貨・不能取貨」**，客戶不會再被配到。
- 退貨記錄會出現在訂單明細的「↩ 退貨記錄」區，以及 WMS 轉貨頁（標示 🔁 退訂單）。

---

## 四、常見問題

**Q：收貨了，但退貨視窗「可退」是 0？**
- 先確認**畫面有沒有重新整理**（剛收完貨可能還是舊畫面）。
- 確認你開的是**對的那張單、對的分店**——同樣的商品可能有別張單在「還沒收貨」的分店，那種就沒貨可退。
- 確認「店端庫存」欄是不是真的有貨；沒貨就退不了。

**Q：客戶已經把貨取走了，還能退嗎？**
- 可以。把「**客戶已取貨後退回**」勾起來，系統會先把貨入庫回店端再退回總倉，最多退到客戶取走的數量。

**Q：一張單部分已取、部分沒取，怎麼退？**
- 沒取的那部分：不勾勾選框，走一般退貨。
- 已取又拿回的那部分：勾起來，另外退一筆。
