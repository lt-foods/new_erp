# 系統更新通知 — 2026/05/06

各位辛苦了！這次更新主要是讓「**改價、加備註、催客人來取貨、處理奧客**」這些日常操作變得更順手。下面用大白話介紹，請花 5 分鐘看一下 🙏

## 一、訂單可以改售價、加備註、整單打折了 💰

**過去：** 訂單成立後就鎖死，要改價只能取消重開。
**現在：** 點開訂單就能改，**所有改完一次按「💾 儲存」**，比較省事。

### 可以改的東西

點訂單 → 看到一張「明細表」，有黃色框框的地方都可以點下去改：

1. **每個商品的單價** — 例如原本 $100，客人吵著要 $90，直接改。
2. **每個商品的折扣** — 可以選「打 9 折（用 %）」或「直接減 $20（用 $）」。系統會自動算給你看。
3. **每個商品的備註** — 例如「客人要不要加蔥」、「指定要冷凍包裝」。
4. **整單折扣** — 一樣可選「9 折」或「減 $50」，會套在整張訂單。
5. **單頭備註** — 整張訂單的整體備註，例如「客人 5/8 才來拿」、「已收現金 $500」。

### 看到的金額會這樣顯示

```
原價 $1000
− 單品折扣 $50  ← 商品本身打折
小計 $950
− 整單折扣 8% (= $76)  ← 整單再打折
= 應收 $874  ← 客人實際要付的
```

### 想改的時候

1. 點黃色框框 → 改成你要的數字
2. 上面會出現黃色提示「⚠️ 您有 N 項未儲存的修改」
3. 可以填「修改原因」（選填，方便事後查為什麼改）
4. 按 **💾 儲存** → 全部一次寫進系統

> 💡 改錯了不要慌，按「取消修改」會復原。

### 想看誰改過、改了什麼

點右上角「📜 查看編輯歷史」，會列出每一筆變更：

| 時間 | 欄位 | 變更 | 操作人 | 修改原因 |

## 二、取貨單會把折扣印得清清楚楚 🧾

**過去：** 列印的小白單只看得到原價。
**現在：** 客人會看到「原價 $230 ~~劃掉~~  特價 $179」，**讓他覺得有賺到** 😄

商品旁邊還會印上備註，例如「↳ 備註：客人不加蔥」，避免出錯。

訂單整體備註（例如「客人 5/8 才來拿」）也會印在小白單上面。

---

## 三、找客人取貨更聰明了 🛒

進入「**取貨**」頁面（左邊選單）→ 輸入姓名/電話/會員編號搜尋客人 → 看到他所有未取訂單。

### 排序變聰明

- **可以取貨的訂單會排在最上面**（綠色「✅ 已到貨」），優先處理
- 同樣可取貨的訂單，**到貨時間最久的排最前面**（提醒你催客人取貨）
- 還沒到貨的擺到最下面（黃色「⏳ 未到貨」）

### 確認取貨前可先印單給客人對

按「✅ 取貨」會跳出對話框 → 旁邊有「**🖨️ 列印小白單**」按鈕，可以**先印給客人看金額對不對，他確認後再按確認取貨**。

確認取貨後，系統會**自動跳出列印頁**（一張大張取貨單 + 一張熱感應小白單）。

## 四、可以「催客人」來取貨了 🔔

每張可取貨的訂單旁邊有個藍色「🔔 通知」按鈕。

按下去 → 系統會推播訊息給客人手機（如果他有裝 LINE/網頁通知）→ 提醒他「您的商品到貨可取」。

訂單列上會顯示「📨 上次通知 5/6 凌晨1:08」，**避免你重複通知客人造成困擾**。

---

## 五、分店收貨會自動通知客人 📦→📱

當你在系統裡按「分店收貨」，**系統會自動把訊息推給所有相關訂單的客人**，不用一張一張通知。

> ⚠️ **黑名單客人會自動跳過**（見下一段）。

---

## 六、奧客處理：黑名單功能 🚫

去「會員」頁面 → 點某位會員 → 看到「管理員設定（不對外顯示）」區塊，有兩個勾選：

- **🔕 不發送取貨/到貨通知** — 勾起來後，分店收貨自動推播會跳過他、手動「🔔 通知」按鈕也按不下去。
- **🚫 禁止此會員加新訂單** — 勾起來後，**小幫手加單頁會擋住，不能幫他加新單**（搜尋下拉會顯示「🚫 黑名單禁加單」紅字、整列灰階）。

---

## 七、暱稱備註（管理員專用，客人不會看到）📝

同一區塊有「暱稱備註」欄位，可以填：
- 「奧客」
- 「老闆親戚」
- 「常退貨」
- 「叫貨容易反悔」

**這個備註只有自己人看得到**，客人在 LIFF 我的介面、列印小白單上都不會出現，請放心使用。

填了之後，**這位會員的姓名旁邊會出現一個橘色 🔒 標籤**，提醒你這位客人需要注意。

---

## 八、合併重複會員（虛擬 + 實體 LINE 會員）🔗

很多時候客人前後分了兩筆會員資料：
- 一筆是用截圖/口頭加單時產生的「虛擬會員」（沒綁 LINE）
- 一筆是他後來自己加 LINE 才出現的真實會員

過去這兩筆是分開的、訂單／點數／儲值無法合併。

**現在：** 開虛擬會員的 detail 頁，會看到右邊「🔗 合併到實體會員」按鈕：
1. 點下去 → 跳出搜尋視窗
2. 搜尋目標會員（姓名/電話/會員編號）
3. 點選 → 確認 → **所有訂單、點數、儲值、卡片、標籤全部搬到實體會員**
4. 虛擬會員會被標記為「已合併」

> ⚠️ 合併不可還原，按之前請確認對的人。

## 九、其他細節

- **彈出視窗（popup）只能按右上角 ✕ 關閉** — 過去點旁邊或按 ESC 會不小心關掉操作中的視窗，現在不會了。
